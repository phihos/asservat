The final native admission run passed the existing observation/RBAC scenarios and four new admission scenarios, including a real negative dry-run probe and loss of enforcement. Earlier runs provided useful failures:

- CEL does not expose namespace UID through `namespaceObject.metadata`; that pin remains in the bounded reader/reconciler.
- Mixed-value CEL map literals require explicit dynamic values.
- An absent primary-resource `subResource` field needs a presence check.
- Object sets passed schema installation but failed structured server-side apply. Generated object lists now use reviewed identity keys; tests include a successful ordinary apply and a rejected escalation using forced apply.
- Admission denial is HTTP 422 by default in the qualified server. `DoRaw` discarded the structured policy cause; the proof path now validates bounded response JSON and uses the structured client-go error. A regression test covers both 403 and 422.
- A tempfile name can contain an underscore, which Kind rejects in a cluster name. The owned-fixture harness now normalizes that character.

The CRD translator refuses unreviewed conditional-rule changes rather than discarding unsupported JSON Schema features. It produces structural AccessBinding/PermissionSource schemas and their protected status subresources. The admission builder checks authenticated Kubernetes actors and both the old and new delegation scopes. It does not install or qualify a guard merely by constructing its resource objects.
