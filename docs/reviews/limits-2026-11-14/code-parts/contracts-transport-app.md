# Numeric limits: internal/contracts, internal/transport, internal/application, internal/console, cmd

This is a read-only audit of asservat-ux at `fix/kimi-session-review` (non-test Go only). The rows are ordered from most to least user-visible. Paths are relative to the repository root. `domain/…` constants are outside this scope. They are named only where an in-scope file enforces them or shows them to users.

Skipped, as the brief instructs:
- per-call I/O `context.WithTimeout(…, 5s/30s/60s)` that bounds one network call;
- pagination page sizes that have a continuation (`limit` defaults of 20 and maximums of 100 in share, live and grant lists; `ClusterObservationPageSize` 64; `CapacityDiscoveryPageSize` 64);
- per-item parser and buffer floors (`httpReadBuffer`/`httpPageBytes` in planning/recorder.go:585-586, `minRawSnaplen` 54, live buffer row/byte caps).

`cmd/` (77 lines) contains no limits.
