# Bounded native context retrieval

Partial C-14/C-21, S-02 and REQ-DLD-001/003. The regional acquisition-role `ContextNativeReader` unwraps and verifies the exact committed context manifest, index and native JSON. It returns at most 4096 bytes under an independently supplied current disclosure lease of at most five seconds. Native evidence remains outside SQL, outbox and MCP result bodies; the caller clears the transient buffer after delivery. Hub/control roles receive no unwrap capability.

Acquisition verification is bounded by the original `WriteUntil`. Native retrieval instead uses the earlier of the current disclosure lease and original `ExpiresAt`, so a developer can inspect a completed capture after collection has stopped. These are separate deadlines. Both paths share complete authenticated decoding and use an actual context deadline during blocking object/KMS reads. Failure, cancellation, changed audience or expired retention returns no plaintext. The first reader supports the only currently implemented native artifact, approved pod-status metadata; later enabled mechanisms must provide their native download path too.

`make context-integration` passed on 2026-10-10 against two owned Kubernetes clusters and real OpenBao/S3/PostgreSQL (`test/results/context-native-integration-check.log`, `context-storage-environment.json`: exit 0, unchanged source, no cleanup failures). Each cluster captured through the product writer/verifier, waited beyond its acquisition window, recovered byte-for-byte identical native JSON with matching SHA-256, rejected invalid/cancelled/audience-mismatched reads and rejected reads after retention expired. The transient synthetic test authority is not production access control. These results do not qualify an HTTP endpoint or browser/MCP download session.

Current catalog entitlement/denies, session preparation/idempotency, disclosure budgets and durable audit, range/resume, relay locality, HTTP headers/cancellation and the public UI/MCP flow still need composition. The reader alone grants none of those permissions and must never be registered as a public endpoint.
