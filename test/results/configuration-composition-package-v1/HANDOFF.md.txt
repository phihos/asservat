## Concrete changes

- Register only private `configuration-role-install`, with no arguments,
  original finite bootstrap behavior, nonzero cancellation/error exit and safe
  fixed phase/remedy output. The partial public-role installer is not registered.
- Generate `ConfigurationRoleInstaller` from matching existing owner/reconciler
  installation/cluster/namespace, source UID, provider roots/endpoints, native
  guard, source-probe and scheduling Lease inputs. Retain actual original
  Deployment/account refs and activation claim. Derive the compiled three-role
  layout and one-connection administrator pool; no selected roles/grants/paths,
  credentials or invented observation is accepted in this generator.
- Generate an inert Restricted hub-worker workload using the existing builder,
  unchanged command/security/RBAC, separate provider credentials and the exact
  installation-derived immutable three-SQL-role/manifest projection. The
  builder neither applies objects nor starts replicas. The current installed
  hub-worker constructor switch is deliberately excluded until actual generated
  manifest handoff is qualified.
- Closed-input/provider-boundary and projection-separation regressions, plus
  the architecture update. No contract/schema/type shape changes are made:
  output uses the four configuration schemas already integrated in v1.
