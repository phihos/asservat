## Concurrency, failures and lifetime

A candidate error ends that worker without being absence, but does not cancel another already-admitted candidate. If all workers finish without a positive, the result is unavailable. The preserved before variant returns on the first error; the new barrier-controlled regression holds an independent positive until that error has returned.

Every positive A locator reserves/spends its original R standby before output. Parallel positive losers remain spent. GET output failure never reissues the locator.
