# Native same-call admission checks

This seven-path package removes exactly two duplicate full current checks from synchronous constructor/attachment plumbing. It does not claim to resolve the whole native preparation availability issue.

`RegisterNativeExchange` retains the initial gate check and the existing Before callback, including all its current/effect checks. Its full post-Before check now passes a private, one-use checked value into the local constructor instead of immediately repeating the same authority traversal inside that constructor. `NativeRegistration.attach` still performs its full current check and compares the exact original operation, certificate, sequence and deadline; its private attachment consumes that same-call value instead of performing a second immediate traversal.

The unexported checked value retains its actual gate, original caller context and original lease. It is not stored on an operation, serialized, or reused across I/O. Local construction and attachment revalidate the clock, context, exact operation/certificate/sequence, known gate closure and monotonic shortening, including after the attachment lock. The existing gate snapshot only vetoes or restricts a newly performed Check; it cannot mint a checked value, renew its deadline or authorize a frame/effect. Context interface values are never compared.

Both public constructors and public `Attach` continue to invoke full `gate.Check`. Final handler admission, every pre/post-frame check, Before/key binding, final SQL completion and application final authorization are unchanged. No SQL, wire, authority lifetime, budget, worker delay or retry changes are included. The unrelated cached release-helper hardening remains outside this package.
