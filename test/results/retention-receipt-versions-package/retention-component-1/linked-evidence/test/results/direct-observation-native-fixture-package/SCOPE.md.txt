## Measured path and limits

The first native matrix is deliberately bounded: four consecutive independent requests on the same H/A/R processes and retained clients/pools, covering namespace candidates, workload candidates, exact workload metadata and namespace guard. Each request is created once before host-to-H dispatch with its original five-second cutoff. Host dispatch, SQL/TLS/native work and return transit all consume it. The already-open R standby retains its original 30-second socket cap and leaf; late attachment never grants five additional seconds.

All existing native clients keep their 20-QPS/20-burst bound. No per-request pool, rate limiter, new grant, warm-up retry or failure retry is introduced. An unavailable first purpose terminates the matrix. The fixture then mutates an annotation on the exact original R Pod and requires no result from the next independently admitted request, followed by joined closure and no available old standby.

Setup/standby and complete-request counters are separate for H, A and R. They record native request counts, HTTP 403 counts separately, other errors and response-header duration. A 403 counter alone does not prove the selected independent denial; the unchanged guard verifies that. SQL reports only pool acquisition counts/durations/empty/cancelled acquisitions, **not SQL statement count or lock duration**. Source ages, whole monotonic latency, original remaining time and fixed terminal categories are included. No URL, query text, arguments, token, credential, evidence payload or identity is emitted in those counters. The actual transfer verdict is logged before subsequent diagnostic status reads.

The metadata-only additions are one namespace LIST; namespace GET/LIST/GET for workload candidates; four exact workload/namespace reads; or the complete existing namespace guard proof. These are structural calls, not a total duration estimate. The full path still needs its actual native timing verdict. Host source-observer pools are retained and measured separately from the helpers; this fixture does not claim full installed HWORK background/shared-client contention, multiple healthy owners, concurrent H requests, aged-bound success or sustained production availability. Existing component regressions cover those authority/lifetime edge cases individually; this first native matrix does not replace later installed qualification.
