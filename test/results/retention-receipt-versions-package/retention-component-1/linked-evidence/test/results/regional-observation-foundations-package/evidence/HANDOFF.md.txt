## Behavior and boundary

The regional producer uses a private snapshot of its actual process-owned
key/CSR/leaf as a restrictive replacement and closure veto. A purpose-specific
native attester result retains the actual complete source already checked by
the unchanged two-read/online-TokenReview/live-workload/guard algorithm. Exact
installed template checks, pinned and current proof roots, and final original
key/leaf/cancellation checks remain mandatory. No enrollment, signing or local
SQL activation is inferred from this snapshot. The existing full observation
method still performs its original source and registry reads.

The remote source consumes four new numbered replies on the same actual TLS
channel and original request. Its calls are spent before I/O, changed or unknown
replies permanently fail the conversation, current SQL49 registry checks remain
separate, and the first proof's deadline cannot be extended by later replies.
The channel permits exactly two proof replies, one bounded metadata call, two
post-result proof replies and the exact original receipt. Its Close cancels and
joins actual admitted method calls; it does not claim remote stream completion.

An empty standby retains only routing/socket identity and its original maximum
30-second hard end. A later request needs fresh candidates and current registry
proof for the same actual TLS owner/leaf. The active interval intersects that
hard end and every original caller/proof deadline; no keepalive or late request
adds a new socket lifetime. Key replacement, leaf renewal, current revocation or
unknown admitted I/O terminates it.

The fixed frame codec and private closed order enforce message kinds, direction,
per-frame bounds, a 12-frame ceiling and aggregate bytes. They grant no authority
and are not yet selected by a concrete stream runtime. The domain now owns the
request digest; the existing transport wrapper delegates to it. Four-purpose
tests compare the exact previous wire algorithm, including dates, optional
fields, nil/empty keys, key ordering and mutations. The v1 domain separator and
existing request IDs/bytes are preserved.
