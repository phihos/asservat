Source only. No compilation, sqlc generation, schema application, test or planner

## Product changes

- Strict current/new-write domain predicates reject empty and literal-null
  versions. Structural checkpoint decoding uses the explicitly historical
  predicate only; all prior record/digest/source checks remain in place.
- `AcceptedRetentionSource` replaces the existing one current-checkpoint read
  with the same query and full row, then additionally validates its actual
  receipt. No additional database round trip or wider interval.
- `RetentionSourceCaughtUp` retains its all-history completion branch and adds
  two invalid-receipt branches plus already-joined root/attempt equality. It
  uses the two partial indexes with their exact row predicates.
- Two public-qualified pure invoker functions, explicit PUBLIC EXECUTE, fixed
  UTF-8/C/search path, no table/time/settings dependencies, no SECURITY DEFINER.
  Only class22 errors become false. No per-role grant inventory change.
- Existing role verifier source review: `public_runtime_roles.go:470` checks
  ambient security-definer functions; `:485` checks exact direct role grants.
  PUBLIC invoker EXECUTE is neither. Initial role/history checks use the same
  distinction. Actual catalog/read-role/denial tests remain required.

The JSONB input size check serializes an already parsed value; retained table
rows already have a 4096-byte text constraint. The bytea predicate rejects
oversize bytes before decoding. The predicates do not impose a global caller
query/allocation limit on arbitrary public SQL expressions.
